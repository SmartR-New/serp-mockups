Gắn token Espresso vào HTML

File này không copy mã màu. Màu, bo góc, bóng và cỡ chữ đều đọc từ espresso-tokens.css.

1. Lấy token

Nguồn là frappe-ui/tailwind/tokens. Bản đã xuất nằm ở espresso-tokens.css: light trên :root, dark trên [data-theme="dark"].

2. Link vào mockup

<link rel="stylesheet" href="espresso-tokens.css"> trong <head>. Font Inter gắn riêng vì token chỉ ghi tên font.

3. Dùng biến

Nền var(--surface-*), chữ var(--ink-*), viền var(--outline-*), góc var(--radius-*).
