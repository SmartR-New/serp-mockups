Inventory Request — workflow & documents

Aligned with PRD v1.6 · Desk mockup · Material Request DocType

PRD v1.6 Form mockup

iMED Inventory Request (ERPNext Material Request). No wrapper DocType: one originating MR on submit spawns linked child MRs (stock vs purchase). PO draft on Stock Manager approve (R-7). Tab Documentations lists linked vouchers.

Stock User only creates/submits. Shortage: Stock Manager sets Request PO @ mgr, then approve creates PO draft + ToDo. Auditor reviews PO (no Create PO). Controller → execute tasks (DN, Packing Slip, QI, Installation).
